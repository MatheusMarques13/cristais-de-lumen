# Cristais de Lumen — versão web

RPG de batalhas por turnos feito no GameMaker. Esta é a versão HTML5, que roda no
navegador do computador, do celular ou do tablet.

**Jogar:** https://matheusmarques13.github.io/cristais-de-lumen/

- Toque na tela ou use as setas e Enter.
- A primeira abertura baixa a arte do jogo (~350 MB); depois fica no cache do navegador.
- O jogo salva sozinho no próprio navegador.

Feito por Matheus Marques e Vicente. Arte, animação e código desenvolvidos com apoio
de inteligência artificial, sempre seguindo a mesma direção de arte: pintura chapada
com contorno de nanquim.
